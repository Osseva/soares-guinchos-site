# Soares Guinchos

Landing page responsiva para serviço de reboque, preparada para uso como página oficial e ponto de entrada do projeto Avalie Fácil NFC.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `styles.css` — identidade visual e responsividade
- `script.js` — comportamento básico

## Publicação

O projeto é estático e pode ser publicado em GitHub Pages, Netlify, Vercel ou hospedagem convencional.

## Canais

A página possui chamadas para WhatsApp, telefone, localização, Google e Instagram.
